📦 Functional Modules

Everything an ATS Needs —
One Platform.

8 deeply integrated modules covering every aspect of vehicle fitness testing operations.

📋
Vehicle Booking & Customer Management
Register customers and vehicles, schedule fitness test appointments, generate unique booking IDs, assign operators and track booking status end-to-end.
Booking ID LMV / HMV Audit Trail
📍
GPS Attendance & Employee Management
Mobile GPS punch-in/out with geofence validation for up to 25 employees. Daily records, late tracking, EOD reports and anomaly flagging for suspicious check-ins.
GPS Geofence EOD Reports 25 Employees
⚙️
Test-wise Task Allocation & Workflow
Configure any number of testing operations. Each operator sees only their assigned queue. Real-time pipeline: Scheduled → Assigned → In Progress → Completed → Verified.
Configurable Ops Real-time Role Isolated
🤖
AI Camera & Number Plate OCR
Snap a vehicle photo on mobile — AI extracts the registration number instantly. Confidence scoring, booking auto-match, duplicate detection and original evidence retained.
AI / OCR Indian Formats Confidence Score
📄
Test Reports & Documentation
Configurable report templates per test type. Submit readings, photos and observations. Admin review, approval or return for correction — full history preserved.
PDF Export Tamper-proof Per Test Type

Fitness Certificate & Expiry Tracking
Record certificate details and validity dates. Automated reminders at 30, 15, 7 and 1 day before expiry. Dashboard view of upcoming and expired certificates.
Auto Reminders Expiry Alerts History
💬
WhatsApp Business API
Official Meta WhatsApp integration. Automated booking confirmations, test reminders, completion alerts and expiry reminders. Delivery tracking and failed message queue.
Meta Official API Bulk Messaging Scheduled

Admin Dashboard & Analytics
Real-time KPIs: bookings, arrivals, test progress, attendance and expiry alerts. Date-wise analytics, employee productivity, Excel/PDF export and full activity audit logs.
Real-time KPIs Excel / PDF Audit Logs

🗺️ Implementation Roadmap

Phased Delivery —
Structured & Predictable

6 clearly defined phases from discovery to production rollout.

1
🔍 Discovery & Validation
Confirm ATS regulatory context, test types, equipment interfaces, report formats, existing workflows and government API requirements.
2
⚙️ Core Operations
Authentication, RBAC, customer/vehicle records, booking system, test-wise task allocation, operator dashboards and admin dashboard.
3
👥 Workforce Management
GPS attendance with geofence validation, EOD reporting, payroll configuration and payslip generation.
4
🔬 Testing & Evidence
Test forms, camera capture, OCR-assisted number plate extraction, test report submission and admin review workflow.
5
🤖 Follow-up Automation
Certificate validity tracking, background expiry jobs (30/15/7/1 day reminders) and official WhatsApp Business API integration.
6
✅ Validation & Rollout
Role permission testing, audit trail verification, backup/restore testing, UAT with client, edge-case handling and production deployment.
